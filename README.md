# student-management-system-Backend

#  Student Management System API

A role-based Student Management System built with **Node.js, Express, TypeScript, and MongoDB Atlas**.

---

## Features

### Admin Panel
- Admin login using JWT authentication
- Add students (name, email, department, password)
- Assign tasks to students with due dates
- View all admins, students, and tasks

### Student Interface
- Student login using JWT authentication
- View assigned tasks
- View task status (pending / overdue / completed)
- Mark tasks as completed

---

## 🛠 Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Swagger (API Documentation)
- Postman

---

## Authentication

- JWT-based authentication
- No cookies or sessions used
- Role-based authorization (Admin / Student)
